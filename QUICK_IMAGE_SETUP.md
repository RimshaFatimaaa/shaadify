# Quick Image Setup Guide

## TL;DR - Minimum Images Needed

**To see images in your app, you need at least 6 images:**

1. Create folder: `assets/images/moodboards/royal/`
2. Add 6 images:
   - `royal_1.jpg`
   - `royal_2.jpg`
   - `royal_3.jpg`
   - `royal_4.jpg`
   - `royal_5.jpg`
   - `royal_6.jpg`

3. Run the app and select "Royal" theme in moodboard screen

## What Kind of Images?

**Moodboard Images (Most Important):**
- Wedding stage decorations
- Table setups
- Flower arrangements
- Lighting setups
- Venue ambiance photos
- Color-coordinated décor

**Image Specs:**
- Size: 400×600 pixels (portrait orientation)
- Format: JPG or PNG
- File size: Under 500KB each

## Folder Structure

```
assets/
└── images/
    └── moodboards/
        └── royal/
            ├── royal_1.jpg
            ├── royal_2.jpg
            ├── royal_3.jpg
            ├── royal_4.jpg
            ├── royal_5.jpg
            └── royal_6.jpg
```

## Where to Get Images

1. **Free Stock Photos:**
   - Unsplash.com → Search "wedding decoration"
   - Pexels.com → Search "wedding"
   - Pixabay.com → Search "wedding stage"

2. **Pakistani Wedding Images:**
   - Search: "Pakistani wedding decoration"
   - Search: "Mehndi decoration Pakistan"
   - Search: "Barat stage decoration"

## Full Setup (All Themes)

If you want images for all 10 themes:
- **Total: 60 images** (6 per theme × 10 themes)
- Create folders for each theme: `royal/`, `pastel/`, `neon/`, `rustic/`, `garden/`, `classic_red/`, `modern_minimalist/`, `vintage/`, `boho/`, `luxury/`
